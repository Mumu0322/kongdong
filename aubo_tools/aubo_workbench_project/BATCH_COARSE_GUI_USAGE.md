# 批量粗定位功能GUI使用说明

## 启动GUI

```bash
cd aubo_tools/aubo_workbench_project
python run_workbench.py
```

## 使用步骤

### 1. 打开"旧定位 / 偏移测试"页面

在工作台主界面，点击"旧定位 / 偏移测试"选项卡。

### 2. 配置批量粗定位参数

在"批量粗定位参数（多孔时可选）"区域：

- **启用批量粗定位模式**：勾选此复选框
  - 启用后，多孔场景下会在340mm一次性检测所有孔
  - 未勾选时，保持传统逐孔粗定位模式

- **批量采集帧数**：默认15
  - 在共同340mm位姿采集的RGB-D帧数

- **批量最少有效帧**：默认10
  - 每个孔至少需要多少帧有效检测

- **每帧最少孔数**：默认为空
  - 留空表示至少检测到1个孔即可
  - 填写数字（如3）表示每帧必须检测到至少3个孔

- **视野边缘余量 px**：默认50.0
  - 规划共同观察位姿时，孔距离视野边缘的安全距离

### 3. 其他必需参数

- YOLO 模型：选择孔洞检测模型
- 手眼结果：选择手眼标定结果文件
- 粗定位高度：340mm
- 精定位高度：260mm
- 粗定位帧/精定位帧：保持默认即可

### 4. 开始定位

1. 勾选"真实运动"（如需实际运动机械臂）
2. 点击"开始两阶段定位"
3. 在弹出的相机画面中，点击选择多个孔位
4. 按Enter/空格键确认

## 工作流程

### 启用批量粗定位模式（多孔）

```
1. 在初始位置选择N个孔
2. 移动到能看到所有孔的340mm共同位姿
3. 采集15帧RGB-D，一次性检测所有孔的位姿和深度
4. 逐个移动到每个孔的260mm位姿，进行精定位
```

### 未启用批量粗定位（传统模式）

```
1. 在初始位置选择N个孔
2. 对每个孔：
   - 移动到该孔的340mm位姿
   - 采集RGB-D粗定位
   - 移动到该孔的260mm位姿
   - 采集RGB精定位
```

### 单孔场景

无论是否勾选批量粗定位，单孔场景都自动使用传统逐孔流程（无需共同位姿）。

## 预期效果

- **3孔场景**：粗定位时间从 ~1.5分钟 → ~30秒（节省约1分钟）
- **5孔场景**：粗定位时间从 ~2.5分钟 → ~30秒（节省约2分钟）
- **质量保持**：批量模式融合多帧数据，精度不降低

## 故障排除

如果批量粗定位失败：
- 系统会自动回退到逐孔粗定位模式
- 检查"运行日志"查看具体错误信息
- 可能原因：
  - 孔位距离过远，无法在一个视野中同时看到所有孔
  - YOLO检测不稳定，未达到最少有效帧数
  - 点云质量差

## 命令行等效参数

GUI中的设置等效于以下命令行参数：

```bash
--batch-coarse-localization \
--batch-coarse-frames 15 \
--batch-coarse-min-valid 10 \
--batch-coarse-view-margin-px 50.0
```

可选参数（仅在填写时传递）：
```bash
--batch-coarse-min-holes-per-frame 3
```
