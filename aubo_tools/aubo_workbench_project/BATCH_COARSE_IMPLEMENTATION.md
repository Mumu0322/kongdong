# 批量粗定位功能实现总结

## 实现完成的功能

为旧两阶段孔洞检测流程增加了批量粗定位功能，支持在340mm高度一次性检测多个孔的位姿和深度。

## 核心实现

### 1. 新增命令行参数

在 [run_yolo_eye_in_hand_optimized.py](run_yolo_eye_in_hand_optimized.py) 中添加：

- `--batch-coarse-localization`: 启用批量粗定位模式（默认关闭）
- `--batch-coarse-frames N`: 批量粗定位采集帧数（默认15）
- `--batch-coarse-min-valid N`: 批量粗定位最少有效帧数（默认10）
- `--batch-coarse-min-holes-per-frame N`: 每帧最少有效孔数（默认None，表示至少1个孔）
- `--batch-coarse-view-margin-px F`: 视野边缘安全余量像素（默认50.0）

### 2. 核心函数

#### `_plan_batch_coarse_group_pose()` (第4229-4346行)
规划能看到所有选中孔的340mm共同观察位姿：
- 计算所有孔的几何中心和平均法向
- 计算目标TCP位姿，确保所有孔在视野内
- 验证所有孔的投影位置在有效范围内

#### `_batch_coarse_localization_at_340mm()` (第4349-4572行)
在340mm共同位姿一次性检测所有孔：
- 采集多帧RGB-D数据（默认15帧）
- 每帧检测所有YOLO孔
- 为每个孔跨帧融合：中心中位数、法向融合、深度中位数
- 返回每个孔的几何参数

### 3. 工作流程集成

在 `_run_sequential_hole_workflow()` 函数中（第4575行开始）：

1. **批量粗定位阶段** (第4705-4813行)：
   - 检查是否启用批量模式且有多个孔
   - 规划共同观察位姿
   - 移动到共同位姿
   - 执行批量粗定位
   - 记录成功和失败的孔

2. **主循环处理** (第4815行开始)：
   - 检查当前孔是否有批量粗定位结果
   - **如果有**：跳过逐孔340mm采集，直接使用批量结果
   - **如果没有**：回退到传统逐孔粗定位流程
   - 继续执行高度修正和260mm精定位

## 使用方式

### 启用批量粗定位
```bash
python run_yolo_eye_in_hand_optimized.py \
    --batch-coarse-localization \
    --batch-coarse-frames 15 \
    --batch-coarse-min-valid 10 \
    [其他参数...]
```

### 保持传统逐孔模式（默认）
```bash
python run_yolo_eye_in_hand_optimized.py [其他参数...]
```

## 向后兼容性

- **默认关闭**：不指定 `--batch-coarse-localization` 时使用传统逐孔流程
- **单孔自动回退**：只选择1个孔时自动使用逐孔流程
- **失败自动回退**：批量粗定位失败的孔自动回退到逐孔粗定位

## 预期性能提升

- **3孔场景**：粗定位从 3×30秒 → 1×30秒（节省约1分钟）
- **5孔场景**：粗定位从 5×30秒 → 1×30秒（节省约2分钟）
- **质量保持**：融合多帧数据，精度不降低

## 数据流程

```
用户选择多个孔
    ↓
[批量模式开启] → 计算共同340mm观察位姿
    ↓
移动到共同位姿
    ↓
批量采集15帧RGB-D
    ↓
为每个孔融合几何参数
    ↓
逐个孔处理：
    ├─ 使用批量粗定位结果
    ├─ 移动到孔的260mm位姿
    ├─ 高度修正
    ├─ RGB精定位
    └─ 记录最终结果
```

## 注意事项

1. **视野限制**：所有孔必须能在一个共同位姿下同时看到，否则批量粗定位会失败并回退
2. **孔间距离**：孔之间距离过大可能导致部分孔在视野边缘，影响检测质量
3. **最佳实践**：建议一次选择3-5个空间上较为紧凑的孔
