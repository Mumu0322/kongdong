# 第四策略：选区外围孔优先分组与拍摄方案

日期：2026-09-16。状态：边缘优先与紧凑度修正版代码已落地，实机精度尚未验证。

## 1. 目标和依据

边缘孔指本轮选中区域最外围的一层孔，不是整个伞架最外圈，也不是相机画面边缘。先确定并分配外围孔，外围组最多3孔；外围分配完成后，再对内部孔分组，内部组最多5孔。两类默认不混组，允许1～2孔，不为凑数放宽几何约束。孔号、地图身份和本轮选择身份不随分组变化。

依据最新完整报告 `two-stage-20260916_105641/report.json`：22孔分为4、3、5、5、5孔，均获得15帧有效观测，但报告没有实际放入判定；正式拍摄中的孔中心集中在1280×800画面的中部，不能认定为镜头画面边缘导致误差。H22实测法向与组规划法向约差9°；H19像素中心散布约0.072 px，但局部平面拟合RMSE约1.92 mm。上述结果提示应同时检查观察姿态和三维几何质量，不能仅凭多帧稳定或组大小判断准确性。

本次假设是：外围孔不再被内部孔拉入较大的共同观察组，可改善局部观察角度和孔中心位置。处理顺序本身不提高精度；最多3孔也不保证精度。RMSE、投影距离及初始/正式坐标差均不能直接当作真实放入误差。

## 2. 外围孔识别

识别依据采用本轮冻结的全部选中孔中心。优先将初始三维中心投影到选区局部参考平面，建立二维邻接关系；初始图像用于显示和人工核对。参考平面只用于识别边界，不替代每孔局部法向和最终三维几何。

实施规则：

1. 按局部孔间距建立邻接图，将距离明显分离的选区拆成独立连通区域，各区域分别识别外围。
2. 第一版对局部二维邻接图计算每个孔的最大邻居角间隙，并结合局部邻居数量识别外层；该方法能保留凹边界和共线侧边孔，记录邻接尺度、角间隙和判定原因。后续如现场形状需要，再补充三角剖分/带宽模型。
3. 不直接只取凸包顶点：它会漏掉近似共线的外围孔，也会跨过凹口。保留所有外边界分量；内部未选孔形成的封闭空洞默认不计作“最外围”，另行标记供复核。
4. 小区域仅有1～3孔、近似共线、边界无法可靠闭合时，将该区域全部标为外围，采用保守小组。
5. 自动识别不确定或邻接尺度敏感时，在预览中标明原因，支持人工将孔改为外围/内部；三维信息不足时可用图像识别作为降级方案，但必须标注依据。
6. 外围/内部分类在分组前冻结。不在移除第一层后重复剥离，否则所有孔最终都会变成外围。

预览必须显示原孔号、外轮廓、外围/内部颜色、组号及每组数量。以人工目视确认的本轮外围作为识别验收基准，不能把自动轮廓当作工件真实边界。

## 3. 两阶段分组

### 外围孔先分配

沿每个连通区域的外轮廓，以空间相邻关系生成1～3孔候选组，不跨区域、不跨凹口凑组。两孔和单孔合法。相邻三孔接近共线时必须继续通过长宽比、组跨度、相邻距离、视野及法向门限；长条形组会造成共同点云覆盖不完整，不能为了凑满三孔关闭紧凑度门限，无法通过时拆成两孔或单孔。

每个候选先通过当前共同视野、边缘余量、组跨度及法向门限，再评价观察质量。候选评价应包括：

- 各孔投影到相机主点的最大归一化距离，避免仅按图像几何中心判断；记录完整孔ROI的边缘余量，不只检查中心在画面内。
- 观察光轴与各孔局部法向的最大夹角，不能只检查法向之间相互接近。
- 组跨度、局部曲面差异及初始几何可靠性。

初始点云只能预测正式观察质量。先以最新22孔数据离线重放，确定可解释的质量分档及候选阈值；不直接凭空指定“某角度一定可放入”。候选若不能满足观察条件，继续拆成2孔或1孔；单孔仍不可行则在运动前报孔号和原因。

### 内部孔再分配

外围孔分配并锁定后，仅对剩余内部孔生成1～5孔候选，优先3～5孔，仍允许1～2孔。内部孔不回填外围组，避免观察位重新被内部孔拉偏。

### 分组目标和预算

当前第一版仍沿用求解器的硬约束、最少组数和紧凑度排序；外围/内部先后顺序及各自上限作为更高层硬约束。正式拍摄后再用观察夹角、ROI余量和放入结果验证是否需要把最差观察质量提升为分组目标，避免未经数据验证就改变已稳定的分组行为。

外围和内部搜索共享本轮分组时间预算，默认沿用10秒；记录各自搜索结果。超时仅接受已经找到且通过约束、完整覆盖的分组，否则停止并报告规划超时。任何回退结果都要重新审核，无重复、无遗漏、外围不超过3孔、内部不超过5孔且不超过用户配置上限。

外围配置上限默认3、可设1～3；内部配置上限默认5、可设1～5。原有统一上限若仍保留，作为两类的共同硬上限，例如显式设为1时两类均按单孔执行。

## 4. 拍摄和运动流程

选择目标孔 → 识别外围/内部 → 预览与必要的人工修正 → 外围分组 → 内部分组 → 全部组校验 → 按组移动并采集 → 逐孔质量判定 → 按现有规则执行最终动作或仅保存评估结果。

默认外围组先拍摄、内部组后拍摄；各类内部允许优化安全移动顺序。最终逐孔执行顺序沿用既有设置，不因外围优先分组自动改成外围优先放入。

高度维持340 mm，指相机光轴方向孔面距离。停稳后额外等待默认1秒，继续可配置；默认15帧、每孔至少10帧有效数据和原质量门保持一致，避免本轮同时改变多个变量。

外围观察位通过小组中心与局部法向规划，优先改善最差孔的离轴程度及观察夹角。第一版通过拆组改善共同姿态，不增加自动低位横移或拍后循环调姿。实际拍摄后记录每孔实测法向与观察方向差，区分初始预测与正式结果；若实测不满足已配置质量门，则标为需复拍/失败，不直接使用不合格结果执行最终接近。

沿用既有安全过渡路径，不能因外围优先而直接低位沿边界连线移动。运动/停稳异常终止本轮；孔级测量不合格保留诊断。仅采集评估模式仍有观察位运动，不执行最终孔位接近。

## 5. 报告和界面

当前策略四默认启用“选区外围优先分组”，报告和分组预览显示外围孔数、内部孔数、两类组数、边界来源和每孔边界距离。分类器已识别孔记录中的 `boundary_class_override`/`manual_boundary_class` 覆盖字段；人工编辑入口尚未接入GUI，接入后必须重新规划并清除旧预览。

逐孔记录：分类及来源、连通区域、距边界距离、人工覆盖标志、组号/组大小、预测及实际离轴距离、观察夹角、平面RMSE、有效帧数和中心散布。逐组记录：拆组原因、触发约束、质量分档、搜索是否完整和耗时。

增加可选的人工实验记录：放入成功/失败/未测试、偏差方向、可测量的偏差值及测量方法。程序执行完成与实际放入成功分别记录，不能互相代替。离线分析输出同孔在不同配置下的中心、法向、成功率和耗时对照。

## 7. 验收和对照实验

离线测试覆盖：规则矩形、扇形和凹形选区；多个不连通区域；边界共线孔；内部漏选孔；1～3孔及近共线选区；人工分类修正；规划超时。验证外围只取一层、分类不随分组移除而改变、外围最多3孔、内部最多5孔、近共线三孔被拆分、无跨区凑组、所有孔恰好分配一次。用最新22孔报告生成新旧分组图，人工核对外围识别与候选观察质量。

实机对照保持相同孔号、工件状态、340 mm、1秒延迟、相机参数、帧数及补偿：

| 配置 | 用途 |
|---|---|
| A：原统一最多5孔 | 基线 |
| B：外围最多3孔、内部最多5孔 | 验证分区小组的改善 |
| C：明确失败外围孔单孔拍摄 | 判断小组共同观察是否仍是主要限制 |

先仅采集评估，确认几何和路径后再记录实际放入结果。对同一批孔交替执行A/B以减小时间漂移影响；每种配置建议至少5轮作为初步比较，结果波动大时再增加轮数。对比外围/内部各自的放入成功率、同孔中心重复性、观察夹角、RMSE和总耗时。没有独立参考测量时不宣称绝对精度提升。

如果B改善外围且内部不退化，可保留该策略；如果C明显优于B，进一步缩小失败区域的组；如果C仍失败，应检查YOLO射线中心、孔面拟合、法向、TCP和ChArUco补偿，不能继续把失败全部归因于分组。当前“纯点云”仍借助YOLO确定ROI和射线，该算法定义本次不变。
