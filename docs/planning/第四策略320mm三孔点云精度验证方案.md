# （历史方案）第四策略：320 mm、每组最多3孔的点云精度验证方案

> 本文保留作历史实验记录。当前实现以《第四策略340mm三至五孔停稳拍摄修改方案》为准：拍摄高度340 mm、每组最多5孔，优先3～5孔，停稳后默认等待1秒。

## 1. 目标与范围

将第四策略的实时点云拍摄高度设为320 mm，每个共同观察位最多处理3个目标孔，验证其重复性、绝对定位误差和成功率。本文为实施及实验方案；运行代码已经按下述参数落地，实机实验仍未执行。

320 mm采用项目已有的高度定义：孔面参考点在RGB相机光轴方向上的距离，不是TCP基坐标Z=320 mm。曲面上同组各孔的实际距离可以不同，应逐孔记录。

每组最多3孔表示一次停靠负责1～3个孔，可选择整个扇区并自动拆组；不要求相机画面只能出现3孔，也不是只采集一帧。

## 2. 当前实现核对

- 第四策略由`coarse_direct_final`启用，实时采集点云，不进入260 mm精定位；点云失败孔记录失败。
- 高度规划使用`cfg.coarse_height_mm`；普通两阶段策略默认仍为340 mm和9孔，第四策略启动后折叠为独立的320 mm和最多3孔参数。
- 第四策略关闭共享粗定位到位后的二次位姿纠偏，实验继续保持这一行为。
- 地图调用时第四策略重新拍摄点云，地图只作为导航及身份种子；建图入口会关闭第四策略，不能把“建立地图”等同于本次实验入口。
- 当前点云采集仍用YOLO框中心确定像素射线和点云区域，记录为`pointcloud_center_from_yolo_ray`。因此这里的“纯点云”指不进入后续RGB精定位，不能称为完全不依赖RGB的三维孔边缘拟合。
- 最终运动还使用现有ChArUco XY补偿。点云测量值与补偿后的执行结果需要分开统计。

## 3. 参数方案

| 参数 | 实验设置 | 说明 |
|---|---|---|
| 策略 | 第四策略 | 实时点云中心直达 |
| 拍摄高度 | 320 mm | 组参考孔面沿相机光轴的目标距离 |
| 单组孔数上限 | 3 | 可以拆为1孔或2孔 |
| 每组采集帧数 | 15 | 首轮固定采集预算，便于对照 |
| 每孔最少有效帧 | 10 | 不足则判失败，不用旧结果填补 |
| 提前结束额外确认帧 | 5 | 当前算法下10+5=15，正常采集不在第12帧提前结束 |
| 停稳后丢帧 | 10 | 沿用当前批量采集默认值 |
| 260 mm精定位、融合、回退 | 关闭 | 保持第四策略数据来源一致 |
| 共享粗位姿二次纠偏 | 关闭 | 记录实际偏差，不额外改变实验观察位 |
| 历史粗定位缓存 | 不作本轮测量结果 | 每轮必须新鲜采集 |

以上是实验起点，不代表320 mm必然更准。降低高度与减少同组孔数的效果要分别通过对照验证。

## 4. 分组及编号

1. 从已经确定的孔集合开始，地图Hxx编号保持现有空间编号，不因重新分组而改变。
2. 使用现有空间邻近、视野边缘、法向差、组跨度约束，在320 mm重新计算共同视野。
3. 增加硬性断言：实际下发采集的每个组只能包含1～3个目标孔。
4. 优先组合相邻、几何紧凑的孔；三个相邻编号不一定在空间上相邻，不能直接按每三个编号切块。
5. 三孔组不满足320 mm视野或姿态约束时继续拆分为2孔、1孔，不为凑数放宽质量门。
6. 图中其他可见孔只用于正常检测；本组关联、采集和统计仅覆盖明确分配的目标孔。

## 5. 操作流程

选择第四策略 → 自动/人工确定目标孔 → 预览320 mm分组及孔号 → 到达各组观察位 → 停稳丢帧 → 15帧点云采集 → 逐孔质量判断 → 输出原始三维坐标及误差报告。

第一阶段仅执行观察位移动和测量，不执行孔位最终接近、下降或夹爪动作。需要独立的“仅采集评估”模式；现有`--no-execute`会禁止观察位移动，不能作为完整的实机采集模式替代品。

第二阶段在测量结果达到现场要求后，用同一配置验证补偿后的最终到位误差。两阶段结果分别保存。

此前100 mm抬升余量、分开横移和调姿的修改针对建图路径，不能假设已覆盖第四策略。实施时应检查第四策略观察位过渡和最终移动的实际调用路径，验证320 mm观察位及机器人本体/相机/夹爪净空；碰撞或运动异常应结束整轮实验并保留报告。

## 6. 精度实验设计

### 6.1 对照配置

| 配置 | 高度 | 每组上限 | 用途 |
|---|---:|---:|---|
| A | 340 mm | 3 | 与B比较高度变化 |
| B | 320 mm | 3 | 本次目标方案 |
| C | 320 mm | 1 | 与B比较多孔共同视野带来的影响 |

选取同一批9～12个孔，覆盖扇区上、中、下及边缘位置。B至少形成若干实际三孔组，否则不能据此评价三孔拍摄。各配置使用相同孔号、相机参数、标定、帧数和质量门，记录实际分组及每孔画面位置。

### 6.2 两种重复性

- 固定位姿重复性：每个观察位保持机器人不动，独立采集10轮，每轮重新取得15帧，统计测量抖动。
- 重新到位重复性：每轮从固定观察起点出发，重新到各组采集；每个配置完成10轮。统计机器人重复到位、手眼转换和测量的综合变化。
- A/B/C交替安排测试顺序，避免所有A先拍、B后拍使时间或温度变化混入对比。
- 多帧融合内的15帧不能当成15次独立到位实验。

### 6.3 绝对误差

必须提供同一坐标系中独立测得的孔心参考值，并记录参考测量方法及不确定度。旧地图、同一相机的另一次点云或ChArUco拟合训练值不能直接作为独立真值。

没有独立参考值时，只报告重复性和配置间差异，不宣称已经达到某个绝对精度。

### 6.4 报告指标

- 每孔基坐标X/Y/Z均值、标准差及相对均值的偏移P95。
- 有独立参考值时：X/Y/Z有符号偏差、XY误差、三维误差的均值/P95/最大值。
- 相机坐标原始中心、经手眼变换的基坐标中心、ChArUco补偿量和最终目标分别记录。
- 每孔有效帧数、平面RMSE、有效点数、关联距离、画面边缘距离、实际光轴距离。
- 各孔及整轮成功率、失败原因、单组及整轮耗时；失败样本必须保留，不能只比较成功样本的误差。

验收阈值采用现场工艺允许的XY/Z偏差及成功率要求，当前未提供这些值，不预设“达到0.1 mm”等结论。若B相对A误差下降且成功率可接受，可保留320 mm；若C明显优于B，再评估是否转为逐孔采集。

## 7. 后续代码改造位置

1. `gui_hole_localization.py`：第四策略显示独立的320 mm高度、3孔上限和“仅采集评估”选项，切换策略时不意外改变其他策略和建图参数。
2. `hole_localization_cli.py`、`hole_localization_models.py`、主入口：统一第四策略参数解析和报告值；保留对照实验显式设置340 mm/1孔的能力，三孔实验上限不允许大于3。
3. `sequential_workflow_shared.py`：使用最终生效高度重新分组，规划后与采集前检查组大小，报告目标高度/实际组孔数。
4. `shared_localization_workflow.py`：保留点云采集及质量门，补齐逐孔三维观测、实际距离、来源记录；审计任何回退路径，禁止用历史坐标替代失败测量。
5. `sequential_hole_execution.py`：采集评估模式在结果保存后结束该孔处理，不触发最终接近；区分点云中心与补偿后的目标。
6. 日志与界面：第四策略中写死的340 mm文案改为实际配置；清理已过时的“RGB几何融合”注释，确保报告与真实算法一致。
7. 新增`tools/summarize_coarse_direct_experiment.py`：读取多轮报告，按孔号、配置、组位置输出明细和对照汇总，不写回正式地图。

## 8. 验证与交付

- 参数测试：第四策略预设320 mm/3孔，显式对照配置正确生效，其他策略和建图不被串改。
- 分组测试：1/2/3/4/7孔输入、边缘和跨行布局均不产生超过3孔的采集组；不改变Hxx身份。
- 模拟流程测试：第四策略不进入260 mm流程、不读取历史结果当测量、不进行二次位姿纠偏；采集评估模式无最终接近或夹爪调用。
- 失败测试：空点云、无效帧不足、关联失败明确落盘；运动异常终止整轮。
- 报告测试：320 mm、帧数、实际孔数、点云来源及补偿前后结果一致可追溯。
- 实验汇总命令：`python tools/summarize_coarse_direct_experiment.py --label A=<报告目录> --label B=<报告目录> --label C=<报告目录> --output-dir <输出目录>`。
- 实机交付：A/B/C对照表、每孔误差及失败明细、代表性点云/叠加图、是否采用320 mm三孔方案的结论。

建议顺序：先使用采集评估入口做B的小规模试拍，再完成A/B/C对照；每轮实验结束后用独立汇总工具生成对照表，不把实验结果写回正式地图。
