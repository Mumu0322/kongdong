# 第3章 功能设计与数值要求

本章定义两条多孔定位功能路径：策略四“340 mm 纯点云定位”和“地图 + 共享精定位 + 本轮锚点纠正”。本章所列数值分为三类：**当前实现参数**、**已有运行数据**和**阶段验收目标**。已有运行数据只说明对应运行记录中的表现；未经过实机重复验证的数值不得写成量产精度结论。

## 3.1 功能范围与模式边界

| 项目 | 策略四：340 mm 纯点云 | 地图 + 共享精定位 + 本轮锚点纠正 |
|---|---|---|
| 主要用途 | 以单一高度点云直接输出孔中心，验证纯点云定位能力 | 复用340 mm粗地图完成导航，在260 mm实时精定位后输出最终XY |
| 正式拍摄高度 | 340 mm | 地图粗种子对应340 mm；共享精拍260 mm |
| 单组目标孔上限 | 外围3孔，内部5孔 | 3孔 |
| 最少孔数 | 软目标3孔；余数组允许1～2孔 | 允许1～3孔；联合刚体求解至少2孔 |
| 最终XY来源 | 当前组340 mm点云中心 | 260 mm实时RGB圆心及组级联合修正 |
| 最终Z/姿态来源 | 当前组340 mm点云局部几何 | 地图/粗定位几何，实时精定位主要修正XY |
| 精定位回退 | 不进入260 mm精定位 | 共享补拍后允许失败孔逐孔精定位 |
| 历史校准依赖 | 无 | 本轮整体纠正不要求逐孔历史模型；孔级残差模型为可选项 |
| 当前阶段定位 | 实验策略，实机精度尚未通过 | 主验证策略，保留逐孔回退作为安全兜底 |

两种模式必须互斥。启用策略四时，关闭260 mm共享精定位、联合XY、共享精定位点云融合和逐孔精定位回退。启用地图共享精定位时，每轮仍需实时采集260 mm图像，地图不得直接提供最终孔位。

## 3.2 策略四：340 mm纯点云定位

本文所称“纯点云”是指最终三维孔中心由340 mm处的RGB-D点云计算；YOLO仍可用于识别候选孔、确定孔ID和限定点云ROI，不表示完全停用RGB图像。

### 3.2.1 功能流程

| 步骤 | 功能 | 数值要求 | 输出 |
|---:|---|---|---|
| 1 | 读取选中区域孔集合 | 当前运行记录为20孔 | 孔ID、初始像素中心、边界分类 |
| 2 | 判定选区最外围孔 | 外围层优先；内部孔后处理 | `edge` / `interior`分类 |
| 3 | 紧凑分组 | 外围每组≤3孔；内部每组≤5孔；优选3～5孔 | 组号、孔列表、紧凑度诊断 |
| 4 | 规划共同观察位 | 相机到孔面目标距离340 mm | 目标TCP、组中心、共同法向 |
| 5 | 等待机械臂停稳 | 停稳总超时45 s | 稳态确认结果 |
| 6 | 停稳后延迟 | 默认1.0 s，可配置范围0～30 s | 延迟实际时长 |
| 7 | 清理运动过程旧帧 | 至少丢弃10帧；清理超时10 s | 丢帧数、帧新鲜度记录 |
| 8 | 点云正式采集 | 最大15帧；每孔至少10个有效帧；额外确认5帧 | 每孔点云中心、平面、法向、质量指标 |
| 9 | 输出最终目标 | 不进行260 mm精拍；点云无效则该孔失败 | 最终孔中心或失败原因 |

340 mm指相机光轴方向到孔面的工作距离，不等于机器人基坐标系中的`Z=340 mm`。单组3～5孔表示该组分配的目标孔数量，不限制画面中出现其他孔，也不表示拍摄3～5帧。

### 3.2.2 分组与视野约束

| 参数 | 当前值 | 判定规则 |
|---|---:|---|
| 外围组最大孔数 | 3 | 最外围孔先分组，不允许因外围优先而放宽紧凑度 |
| 内部组最大孔数 | 5 | 优选3～5孔，余数和几何限制下允许1～2孔 |
| 视野安全边距 | 50 px | 任一目标孔不得落入边缘安全区 |
| 图像跨度比例上限 | 0.55 | 组内投影包围盒宽、高均不得超过图像尺寸的55% |
| 组点集长宽比上限 | 2.0 | 超限时拆组，避免近似直线分组 |
| 相邻距离系数上限 | 1.8 | 相邻孔距离不得超过最近邻中位数的1.8倍 |
| 组内XY最大直径 | 180 mm | 超限时拆为更局部的组 |
| 组内法向离散上限 | 8° | 超限时不得共用一个观察姿态 |
| 分组搜索超时 | 10 s | 超时后只能使用已验证的完整覆盖结果或有界回退 |

外围优先只决定处理顺序。紧凑度、视野跨度、XY直径和法向离散门限对外围组和内部组同时生效。最后不足3孔时允许1～2孔成组，但报告必须记录`remainder_or_geometry_constraint`等原因。

### 3.2.3 采集、超时与失败条件

| 参数 | 当前值 | 失败条件 |
|---|---:|---|
| 正式采集帧预算 | 15帧 | 达到采集超时仍未完成 |
| 每孔最少有效帧 | 10帧 | `<10`帧时该孔不得输出正式点云中心 |
| 达标后额外确认帧 | 5帧 | 用于确认短时稳定性；总帧数仍受15帧限制 |
| 旧帧丢弃数量 | 10帧 | 未追上新鲜帧时不得开始正式融合 |
| 旧帧清理超时 | 10 s | 超时中止当前组并记录阶段 |
| 正式采集超时 | 60 s | 超时中止当前组，禁止无限等待SDK |
| 连续取帧失败上限 | 3次 | 达到3次立即中止当前组 |
| 停稳等待超时 | 45 s | 未确认停稳时禁止采集 |
| 停稳后额外等待 | 1.0 s | 从停稳确认后开始计时 |

程序必须输出当前阶段、当前组、计划帧数、已处理帧数、有效孔数和已耗时。取消请求应在单次SDK调用返回后生效，并在报告中区分“用户取消”“采集超时”“连续取帧失败”和“质量门失败”。

## 3.3 地图 + 共享精定位 + 本轮锚点纠正

### 3.3.1 功能流程

| 步骤 | 功能 | 数值要求 | 输出 |
|---:|---|---|---|
| 1 | 加载粗地图 | 地图版本、扇区、相机和手眼指纹必须一致 | 地图孔ID及340 mm粗几何 |
| 2 | 共享精定位分组 | 每组≤3孔，保持空间紧凑 | 260 mm共享组列表 |
| 3 | 首批组实时采集 | 最大8帧，每孔至少5个有效稳定帧 | 每孔严格RGB圆心和直接XY |
| 4 | 建立本轮整体纠正 | 至少4个锚点，且来自至少2个共享组 | 地图到本轮现场的二维平移和旋转 |
| 5 | 修正后续组 | 每孔XY修正≤5 mm | 修正后的地图种子和共享拍摄中心 |
| 6 | 组级联合精定位 | 联合残差≤1.0 mm，平移≤5.0 mm，偏航≤3.0° | 联合内点及每孔预测XY |
| 7 | 失败孔恢复 | 原位补帧≤4帧，共享补拍≤1轮 | 补拍结果或逐孔回退列表 |
| 8 | 最终位置计算 | 实时精定位提供XY，粗几何提供Z和姿态 | 每孔最终目标和来源记录 |

地图只承担孔身份、粗导航和粗几何参考。每次运行必须重新采集260 mm精定位图像。历史逐孔坐标不得绕过实时精定位直接成为最终目标。

### 3.3.2 共享精定位参数

| 参数 | 当前值 | 功能约束 |
|---|---:|---|
| 精拍高度 | 260 mm | 使用RGB圆心，粗阶段几何用于射线求交 |
| 单组最大孔数 | 3 | 超过3孔必须拆组 |
| 视野安全边距 | 50 px | 目标孔不得进入边缘安全区 |
| 组内图像跨度上限 | 0.60 | 包围盒宽、高均≤图像尺寸60% |
| 组点集长宽比上限 | 1.8 | 防止直线型松散分组 |
| 相邻距离系数上限 | 1.8 | 保持局部紧凑 |
| 法向离散上限 | 5° | 超限孔不得共用观察位 |
| 最大采集帧数 | 8帧 | 达到5个稳定有效帧后允许提前结束 |
| 最少有效帧 | 5帧 | `<5`时进入恢复流程 |
| 稳定门最少帧 | 5帧 | 与有效帧门同时满足 |
| 停稳后丢帧 | 10帧 | 确认相机队列追上实时帧 |

| 逐孔回退 | 启用 | 共享补拍后仍失败的孔进入逐孔精定位 |

### 3.3.3 组级联合门限

| 参数 | 当前值 | 判定 |
|---|---:|---|
| 联合最少孔数 | 2孔 | 三孔组可隔离1个离群孔；两孔组无第三点仲裁 |
| 联合最少有效帧 | 5帧 | 不足时联合结果无效 |
| 孔级残差上限 | 1.0 mm | 超限孔从联合内点集合剔除 |
| 整组平移上限 | 5.0 mm | 超限时进入本轮整体漂移判断或恢复流程 |
| 整组偏航上限 | 3.0° | 超限时不得接受联合变换 |
| 跨帧平移稳定门限 | 0.25 mm | 超限表示联合变换不稳定 |
| 跨帧偏航稳定门限 | 0.15° | 超限表示联合旋转不稳定 |
| 局部残差保留权重 | 0.25 | 联合结果为主，保留有限加工偏差 |
| 局部残差限幅 | 0.5 mm | 超限部分不进入最终联合XY |

联合变换用于估计组内共同漂移和识别离群孔。一个孔失败时，只允许该孔进入恢复或回退，不得自动废弃同组已经通过质量门的其他孔。

### 3.3.4 本轮锚点整体纠正

| 参数 | 当前设计值 | 规则 |
|---|---:|---|
| 最少实时锚点 | 4孔 | 少于4孔时保持原地图种子 |
| 最少来源组数 | 2组 | 防止单组共同偏差被传播到全扇区 |
| 锚点内点残差 | ≤1.5 mm | 超限锚点作为离群点剔除 |
| 本轮中心整体位移 | ≤10.0 mm | 超限时禁止启用纠正 |
| 本轮整体偏航 | ≤2.0° | 超限时禁止启用纠正 |
| 单孔种子最大修正 | ≤5.0 mm | 超限孔保留原地图种子 |
| 静态历史偏差直接应用 | 0次 | 未完成本轮对齐前禁止应用 |
| 最终坐标替代权限 | 禁止 | 纠正只作用于后续种子和共享拍摄位置 |

本轮整体纠正默认直接以地图孔位与实时共享孔位建立二维刚体关系，不要求预先进行逐孔标定。前两个共享组承担锚点建立任务；满足4孔、2组和残差门限后，纠正应用于后续共享组及失败孔共享补拍。每加入新的稳定孔，允许重新估计本轮变换，但新结果未通过门限时必须继续使用上一个有效变换。

### 3.3.5 可选孔级残差模型

单次逐孔运行不得直接生成生产孔级残差。孔级模型只有满足下列数值要求后才允许启用：

| 项目 | 启用门限 |
|---|---:|
| 独立逐孔运行次数 | ≥3轮，建议5轮 |
| 每孔有效样本数 | ≥3个 |
| 地图孔匹配覆盖率 | ≥95% |
| 单孔修正绝对值 | ≤5.0 mm |
| 留一运行验证 | 使用模型后P95误差不得高于未使用模型 |
| 变差孔比例 | ≤10% |
| 地图/相机/手眼/TCP版本 | 必须完全匹配 |

现有逐孔参考运行`two-stage-20260916_153939`与地图完成26/26个空间匹配，匹配距离中位数0.872 mm、最大2.495 mm。该数据只有1轮，状态保持`provisional_single_reference_run`，可用于诊断和离线比较，不作为孔级生产补偿的充分证据。

## 3.4 恢复、回退与安全边界

| 异常类型 | 判定示例 | 处理顺序 |
|---|---|---|
| 时间不稳定 | 有效帧<5或圆心离散度>0.35 px | 原位追加≤4帧 → 失败孔共享补拍≤1轮 → 逐孔回退 |
| 视野/锚点异常 | 几何圆心距锚点>5 px | 直接重新规划失败孔紧凑补拍位，避免在同一位置重复无效帧 |
| 组级平移超限 | 平移>5 mm | 检查本轮4孔/2组整体纠正；仍不一致则只处理失败孔 |
| 单孔联合离群 | 孔级残差>1 mm | 接受组内其他内点，仅离群孔补拍或回退 |
| 整体纠正异常 | 位移>10 mm、偏航>2°或残差>1.5 mm | 禁止传播纠正，继续使用原地图种子 |
| 无有效视觉结果 | 0/5有效帧 | 模型不得代替实时检测，执行补拍或逐孔回退 |

所有自动修正都必须可追溯。每个孔至少记录：原地图种子、纠正后种子、纠正量、锚点孔集合、整体平移、整体偏航、拟合残差、共享拍摄位姿、最终定位来源和回退原因。

## 3.5 功能状态结论

| 功能 | 状态 | 结论 |
|---|---|---|
| 策略四340 mm拍摄 | 已实现 | 参数、超时和停稳流程已落地 |
| 策略四外围优先 | 已实现 | 134622中7个外围组先于2个内部组执行 |
| 策略四紧凑分组 | 已实现 | 外围实际形成7个2孔组，未强行凑成直线三孔组 |
| 策略四点云定位精度 | 未验收 | 孔18～20现场效果较差，不能作为生产方案 |
| 地图执行与260 mm共享精定位 | 已实现 | 164346完成26/26孔，其中20孔共享、6孔逐孔回退 |
| 本轮锚点整体纠正 | 方案已定义、参考模型对齐版已实现 | 4孔、2组、1.5 mm残差、10 mm位移、2°偏航和5 mm单孔限幅；直接地图对齐模式仍需完成代码解耦和实机验证 |
| 孔级历史残差模型 | 诊断状态 | 现有1轮参考数据不足，至少3轮后再评估启用 |
| 共享接受率≤15%回退目标 | 未达到 | 当前最好回退率23.08% |
| 最终连续插入验收 | 未完成 | 需连续3轮记录实际插入结果 |

本阶段主线应采用“粗地图导航 + 260 mm实时共享精定位 + 本轮锚点整体纠正 + 失败孔逐孔回退”。策略四保留为对照实验路径，不继续通过增加点云帧数或放宽分组来推定精度提升。后续评审以共享接受率、插入成功率、单孔时间和错误接受次数四项数值共同决定方案是否进入生产验证。
