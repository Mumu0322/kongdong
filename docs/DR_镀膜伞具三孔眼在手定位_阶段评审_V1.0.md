## 2. 工作内容与当前结果

项目最终需要的是机械臂的 TCP 目标，不是图像上的孔中心。伞架孔位处在局部曲面上，视觉计算出的孔中心还要经过手眼变换、工具 TCP 和运动规划，才能变成机械臂可执行的位姿。本次评审看从选孔到实际到位 TCP 的记录，不只看单帧检测框或像素坐标。

### 2.1 现场任务和当前难点

本项目用于将镜片依次放入镀膜伞架上的三个孔位。系统先计算孔位，再换算成机械臂可执行的 TCP 目标，使工具以合适姿态接近孔位。当前是否真正放入孔洞，仍由现场人员人工确认；记录中的 `placement_confirmed` 表示该孔已执行安放动作并由人员确认，不代表已有力控、接触传感或自动视觉复核。

本项目对象为镀膜伞具，其表面具有曲率并伴随反射。在近距离观察时，深度数据在孔周围会出现局部波动；这会使单帧表面拟合的法向和孔面距离不够稳定。与此同时，机器人最终执行的是 TCP 位姿，而视觉侧首先得到的是相机坐标下的孔中心；两者之间还包含手眼变换、工具 TCP、姿态和 XY 系统偏差。若直接把单帧视觉坐标下发给机器人，误差来源会叠加，且无法对三孔的执行结果建立统一追溯。

本阶段要把识别结果换算成可执行的 TCP 目标。粗定位用于确定孔周局部表面和接近姿态；精定位在较近距离减小圆心波动；ChArUco 数据用于修正视觉 XY 与示教 TCP XY 之间的系统差。

### 2.2 从单孔到三孔的做法

最初现场只要求单孔操作，因此围绕被选中的参考孔完成粗定位、精定位和安放验证。需求改为三孔后，三个孔共用一次粗定位和一次精定位的相机姿态、局部几何，再分别计算目标 TCP。这样不用为每个孔重复粗定位，也避免三个孔分别使用不同的局部参考。

目前要区分参考孔和另外两个孔。用于粗定位的参考孔能稳定放入孔洞。另两个孔已经有坐标计算、安放动作和 `placement_confirmed` 记录，但受相对 XY 误差影响，能否放入仍不稳定。因此三孔流程已跑通，但还不能说三个孔都能稳定放入。

方案采用一次粗定位、一次精定位，同时完成三孔推算。先在原点选择参考孔，并在约 340 mm 执行 RGB-D 粗定位和居中/垂直闭环。闭环复采后，程序在粗定位确认位锁定三孔身份，并用粗阶段表面模型给出每个孔的粗中心、朝相机法向和孔面姿态。随后保持粗阶段最终姿态下降到约 260 mm，精拍阶段不重新选择三孔，也不使用新的深度数据更新表面；它只把粗阶段三孔投影为 RGB 跟踪锚点，再对每孔进行圆心多帧融合。最终中心来自精拍 RGB 圆心与粗阶段表面模型求交，最终姿态来自粗阶段三孔位姿。

执行顺序为“视觉孔中心 → ChArUco XY 修正 → TCP 目标”。XY 使用 9 点 ChArUco 仿射模型修正，Z 不使用该模型修正。三个孔逐个安放时，先抬 Z，再移动 XY 和姿态，最后下降 Z；到最终点后基坐标 Y 正方向再移动 +0.2 mm。每个孔都保存目标 TCP 和实际到位 TCP。

### 2.3 粗定位和精定位分别做什么

粗定位使用 RGB-D 获取孔周局部表面点，估计局部法向，并根据孔中心、相机光轴和局部表面法向的偏差进行校正。闭环确认后，粗定位还负责锁定三孔身份，并输出三孔粗中心、法向和孔面姿态；球面模型可用时按球面给每个孔独立法向，球面不可用时退回冻结局部平面。

精定位只使用 RGB。YOLO 用来刷新粗阶段投影锚点附近的 ROI，最终圆心由 ROI 内的圆/椭圆边缘拟合和多帧融合得到，质量不合格的帧按规则剔除。融合圆心对应的像素射线与粗阶段表面模型相交后得到三维孔中心；倾斜圆心修正用于减小投影椭圆中心的偏差。这样，近距离深度波动不直接影响精拍圆心融合，三孔姿态也不会被全部压到精定位阶段。

ChArUco 模型用于补偿视觉 XY 到示教 TCP XY 的系统差，不替代手眼标定，也不修改视觉 Z。该模型是由独立 9 点 ChArUco 触碰记录得到的二维仿射映射；训练残差和留一角点交叉验证误差在本 DR 中单独报告。当前状态为 `needs_more_or_better_touch_data`，因此只作为实验阶段的 XY 修正依据。

### 2.4 已有一次三孔运行结果

在 `two-stage-20260729_170949` 成功运行中，粗定位和闭环复采均获得 15/15 有效帧；闭环后中心偏移为 0.614 px、法向误差为 1.569 deg。三孔 RGB 精定位的圆心 P95 分别为 0.117 px、0.362 px 和 0.258 px，均保留了原始帧数、有效帧数及离群帧记录。三孔均匹配为 70 mm 孔径，倾斜圆心修正量约 0.128–0.130 mm，XY 修正量、目标 TCP 与实际到位 TCP 均已写入附录。

本次记录中，三个孔都按顺序完成了 `placement_confirmed` 安放动作，每孔均执行最终基坐标 Y `+0.2 mm`。RGB 相对定位实验在 200–300 mm 的 11 个高度全部通过质量门，300 mm 为最佳高度；70 项离线测试通过。手眼候选和 ChArUco XY 模型仍保持原始记录中的实验状态，因此本结果只说明实验流程已经跑通，不作为生产验收或外部绝对精度结论。

### 2.5 几个关键做法

这张表把五个关键做法放到同一张图里：局部曲面决定姿态，共用粗拍和精拍决定三孔如何取坐标，圆心计算、TCP 换算和接近路径决定最终怎样移动。发生偏差时，可以按表中的做法回查对应环节，而不是只检查 YOLO 检测框。

| 做法 | 为什么这样做 | 怎么实现 | 对安放的影响 |
|---|---|---|---|
| 以孔所在局部曲面为姿态参考 | 伞具不是全局平面，使用桌面水平或固定世界姿态不能保证 TCP 垂直孔面。 | 粗阶段由孔周深度估计局部法向，规划相机光轴和精拍共用姿态。 | 输出的精拍 TCP 姿态对应局部孔面，不把“垂直”误写为全局 Z 方向。 |
| 一次粗拍/精拍同时覆盖三孔 | 对每孔重复进行粗定位会增加运动次数，也会让三孔使用不同的几何参考。 | 粗定位确认位先锁定三孔并生成粗中心、法向和孔面姿态；精拍位只刷新锚点并采集 RGB ROI。 | 三孔最终 TCP 姿态来自粗阶段三孔位姿，精拍主要修正圆心。 |
| 将孔识别与圆心计算分开 | YOLO 检测框可用于锁定目标区域，但检测框中心不是最终几何中心。 | YOLO 仅给出候选和 ROI；最终中心由圆/椭圆边缘拟合及多帧融合得到。 | 报告记录的是融合圆心 P95、离群帧和椭圆质量，而不是仅记录检测置信度。 |
| 将视觉坐标与机器人 TCP 目标分开 | 孔中心是工具点目标；机器人需要执行的是已考虑工具 TCP、姿态与平面内系统差的 TCP。 | 像素去畸变后构造射线，与固定局部表面参考求交；再将视觉 XY 通过 ChArUco 仿射映射到 TCP XY。 | 附录同时保存孔中心、目标 TCP 与实际到位 TCP，避免将三者混为同一个坐标。 |
| 将接近路径与最终安放分开 | 曲面目标附近不适合在低高度进行大范围 XY 横移。 | 每孔先抬 Z、再移动 XY/姿态、后降 Z，最后执行 Y `+0.2 mm`。 | 运动记录含顺序、安全 Z、最终 Y 修整和 `placement_confirmed` 状态。 |

这里记录的是设计取舍和实际实现，不是算法排名。各做法的作用需结合后面的 RGB 实验、ChArUco 模型结果和三孔运行记录一起判断。

### 2.6 坐标怎么换算、哪些结论还不能下

坐标计算顺序为：粗定位三孔身份与粗位姿 → 精拍 RGB 图像圆心 → 去畸变像素射线 → 粗定位后保存的表面模型 → 孔中心基坐标 → ChArUco 修正后的 TCP XY 和粗阶段孔面姿态 → 每个孔的实际到位 TCP。手眼候选负责相机坐标与机器人坐标之间的转换。工具 TCP 将孔中心的工具点目标换算成机器人需要执行的 TCP 位姿。ChArUco 模型只补偿最后一步的 XY 系统差。

这些环节分开记录后，出现偏差时可以分别检查图像圆心、表面几何、手眼、TCP 和实际执行，不需要把所有误差都归到 YOLO 上。

后续同类伞具可以沿用本项目的处理顺序和记录字段：先用 RGB-D 建立局部几何，再在较近距离用 RGB 求圆心；多个孔共用一次姿态和几何参考；每个孔仍单独记录圆心质量、XY 修正、目标 TCP 和实际到位 TCP。工装、相机安装或 TCP 示教发生变化时，需重新采集相应标定数据。

本阶段没有验证外部基准坐标、长期重复性、量产节拍，也没有完成手眼候选的独立验证。现有记录只说明：在已记录的实验配置下，定位、坐标计算和顺序安放已经完成。其他精度或生产结论需要新的独立实验记录支持，不能从本 DR 直接推出。

## 3. 当前方案与实现状态

这张流程表把一次运行拆成七步。前 3 步建立参考孔和固定局部表面参考，第 4、5 步在精拍位置计算三个孔中心，第 6 步只修正 TCP 的 XY，最后一步按“先抬 Z、再走 XY、后降 Z”执行安放。

| 序号 | 阶段 | 实施内容 | 输出 / 约束 |
|---|---|---|---|
| 1 | 原点选孔 | RGB-D 画面中选择参考孔，估计孔周局部表面。 | 孔中心、局部法向与粗拍目标。 |
| 2 | 340 mm RGB-D 粗定位 | 将相机光轴对准局部孔面，在目标附近采集 RGB-D；闭环确认后锁定三孔身份。 | 三孔粗中心、局部表面、每孔法向与孔面姿态。 |
| 3 | 闭环居中/垂直校正 | 基于画面中心偏移和法向误差进行小幅校正后复采。 | 保存粗阶段深度平面，作为后续射线求交的固定参考。 |
| 4 | 260 mm RGB 精定位 | 仅使用 RGB；YOLO 提供 ROI，椭圆/圆边缘拟合获得三孔圆心。 | RGB 圆心多帧鲁棒融合。 |

流程结束时，程序能够给出目标和实际到位 TCP；镜片是否真正进入孔洞仍由现场人员确认。后续如果加入力控、接触传感或末端视觉，这一步才可以从人工判断变成可记录的自动判定。

闭环复采后，粗阶段测得的深度表面保存为固定局部表面参考；精拍阶段不读取深度，使用 RGB 圆心及该参考与像素射线的交点推算孔中心。最终 TCP 保持精拍姿态，XY 采用 ChArUco 模型修正，Z 直接采用视觉基坐标结果。

### 4.2 ChArUco TCP-XY 仿射模型

ChArUco 模型用于把视觉得到的 XY 换成更接近示教 TCP 的 XY。9 个触碰点给出了模型覆盖范围；仿射矩阵和偏置是实际换算参数；训练残差与留一角点结果一起判断模型是否能离开已有点继续使用。

| 项 | 记录值 |
|---|---|
