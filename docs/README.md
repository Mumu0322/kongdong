# 文档目录

主项目文档按用途分层，避免把当前评审、规划稿和历史材料混在同一目录。

| 目录 | 用途 | 当前规则 |
|---|---|---|
| `reviews/` | 当前阶段评审和发布前审查材料 | 以当前有效评审材料为准 |
| `planning/` | 技术方案、设计草案和实施计划 | 方案不等于已实现能力 |
| `archive/` | 已过期的评审、旧流程和历史证据 | 只用于追溯，不作为当前运行依据 |

Markdown 是工程正文的首选来源；同名 DOCX/HTML 是交付或阅读格式，不单独作为代码行为的依据。

当前运行行为以代码和测试为准；历史专项评审材料已移入归档或从当前主线移除。
