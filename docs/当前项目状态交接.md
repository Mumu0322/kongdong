# 当前项目状态交接

## 1. 项目目标

本项目的目标是：从固定取料位逐片取出镜片，将镜片放入当前镀膜伞架上由操作者选定的目标孔。

当前 MM 主流程主要负责伞架孔位的视觉定位和机器人到位。项目中有独立的夹爪控制窗口和驱动，但夹爪取放动作目前尚未接入 MM 主流程自动联动。

## 2. 当前对象与基本假设

- 当前对象是弧面镀膜伞架。
- 当前主运行链路不读取或依赖 CAD 模型。仓库中虽然保留有 STEP 文件，但不参与当前孔位定位。
- 不假设固定的孔位布局。
- 不假设每轮固定处理某个数量的孔。
- 每轮可由操作者在初始 RGB-D 画面中选择任意数量的有效目标孔；实际数量仍受检测、共同视野、机器人可达性和定位质量门限制。
- 镜片放入时当前只关注目标中心和高度，机器人末端使用固定 Rz 约束。
- 最终目标计算还会使用当前 ChArUco TCP XY 仿射补偿模型；该补偿模型仍需结合独立真值完成生产验收。
- 当前项目不负责自动判断孔内是否已经有镜片，目标孔状态由现场流程保证。

## 3. 当前运行流程

```text
初始 RGB-D 画面
    ↓
人工选择任意数量的有效目标孔
    ↓
确定执行顺序：选中顺序或自动优化顺序
    ↓
逐孔执行
    ├─ 尝试验证并复用粗定位缓存
    ├─ 缓存验证失败或不可用时，回退到逐孔粗定位
    ├─ 精定位
    ├─ 计算固定 Rz 约束下的目标位姿
    ├─ 机器人移动到目标位置
    ├─ 默认等待操作者确认后继续下一个孔
    └─ 可恢复的定位质量失败时重试；仍失败则记录为 deferred、跳过并继续后续孔
    ↓
本轮结束，进入下一轮人工选孔
```

当前定位流程包含：

- 任意数量有效目标孔的人工选孔（受检测、视野、可达性和质量门限制）；
- 每个孔的局部平面和法向估计；
- 340 mm 粗定位与 260 mm 精定位；
- 固定 Rz 的目标位姿规划；
- ChArUco TCP XY 仿射补偿；
- 粗定位缓存验证和失配回退；
- 逐孔确认、可恢复定位失败重试，以及定位质量失败后的继续处理。

相机启动、机器人运动、用户取消或其他流程级异常可能直接终止本轮，不保证所有异常都能按单孔跳过。

## 4. 运行证据说明

运行报告统一保存在：

```text
aubo_tools\data\hole_localization_runs
```

本节不固定维护某一批运行目录。每次新增运行后，应以对应目录中的 `report.json` 为准，至少核对：选孔数量、每孔最终状态、是否实际执行机器人运动、是否使用实验手眼、粗定位缓存策略和实际执行顺序。

截至本交接文档编写时，最近一组连续运行曾出现“每轮选择 20 个孔并完成 20/20 孔”的结果；这只是当时的实验选取，不是系统要求，也不是每轮任务的固定数量规则。若某轮因未确认下一轮而停止，不能把该状态解释为当轮孔定位失败，但仍应以该轮 `report.json` 中的每孔状态为准。

此前连续运行均未启用自动优化顺序，不能仅凭这组数据证明自动优化顺序已经经过现场验证。后续新增运行应注明是否启用了自动优化，以及实际执行顺序。

## 5. 当前边界

- 夹爪可通过独立窗口手动控制，但取放动作尚未接入 MM 主流程自动联动。
- 当前不负责自动判断孔是否已有镜片。
- 当前尚未用实际镜片放置成功率作为验收指标。
- 当前运行使用实验手眼结果，不能直接视为生产授权结果。
- 当前运行数据证明了多孔连续定位链路可以运行，但不代表单孔、少量孔、分散孔和所有选孔顺序都已验证。

### 6.2 默认安全行为

- 默认仅预览，不下发机器人运动；只有明确启用“真实运动”或命令行 `--execute` 后才允许运动。
- 默认不允许把未通过生产验证的实验手眼结果直接用于运动；实验运行需要显式开启实验手眼覆盖选项，并应在报告中记录。
- 默认逐孔完成后等待操作者确认；只有明确开启“自动检测下一孔”后，孔间才会连续运动。
- 真实运动前必须确认机器人工作区、工装/镜片状态、急停可用、当前 TCP 和回原点路径安全。
- 预览模式不能替代真实相机、机器人和工艺安全验证；真实运动也不等于镜片已经成功取放。
